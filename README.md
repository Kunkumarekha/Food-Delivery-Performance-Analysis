# 🍔 Food Delivery Performance Analysis Using Python Pandas

## 📌 Project Overview

This project analyzes food delivery operations to identify delivery delays, restaurant performance, customer satisfaction, peak ordering hours, and order cancellation patterns.

The objective is to transform raw food delivery data into meaningful business insights using Python.

## 🎯 Business Objectives

- Analyze delivery delays.
- Identify peak ordering hours.
- Evaluate restaurant performance.
- Analyze customer ratings.
- Calculate order cancellation rates.
- Compare city-wise delivery performance.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📊 Key Findings

- Total Orders: 20
- Delivered Orders: 18
- Cancellation Rate: 10%
- Average Customer Rating: 3.69/5
- Late Delivery Percentage: 50%
- Fastest Restaurant: Food Hub
- Busiest Ordering Hour: 12 PM

## 🔍 Pandas Concepts Covered

- Data Cleaning and Preprocessing
- Missing Value Handling
- Duplicate Removal
- GroupBy and Aggregation
- Feature Engineering
- DateTime Operations
- Pivot Tables
- Data Visualization
